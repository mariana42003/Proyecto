SOBRE EL PROYECTO

Kronos-Inventario es un sistema desarrollado para facilitar y centralizar los diferentes procesos relacionados con la gestión de inventarios dentro de una organización.

La plataforma integra diferentes módulos que permiten administrar proveedores, órdenes de compra, materiales, movimientos de inventario, alertas y garantías.

El objetivo es proporcionar una herramienta organizada, eficiente y escalable para mejorar el control de los recursos y facilitar la gestión de la información.

MÓDULOS DEL SISTEMA
01. Gestión de Proveedores

Módulo encargado de administrar la información relacionada con los proveedores y facilitar el control de las relaciones comerciales.

Responsable: Mariana Martínez

02. Gestión de Órdenes de Compra

Permite crear, administrar y realizar seguimiento a las órdenes de compra necesarias para el abastecimiento de materiales.

Responsable: Mariana Martínez

03. Gestión de Materiales y Clasificación

Permite registrar, organizar y clasificar los diferentes materiales utilizados dentro del sistema de inventario.

Responsable: Erick Vasquez

04. Gestión de Inventario

Módulo encargado de controlar los movimientos y existencias de los materiales dentro del inventario.

Funciones principales:

Registro de entradas.
Registro de salidas.
Control de existencias.
Gestión de alertas.
Seguimiento de movimientos.

Responsables: Manuel Vigoya y Evert Arias

05. Gestión de Garantías

Permite administrar y realizar seguimiento a las garantías asociadas a los materiales o productos registrados en el sistema.

Responsable: David Villanueva
